# 테스트 목록

자동화된 단위 테스트의 전체 목록이다. 테스트를 추가·수정·삭제하면 이 표도 함께 고친다.

- 마지막 반영일: 2026-11-06 (#44)
- 테스트 수: 46개 (파일 5개)

## 실행 방법

```bash
npm test                                                   # 전체 테스트
node --test src/app/admin/auth.test.mjs                    # 파일 하나만
node --test 'src/app/\[lang\]/contact/actions.test.mjs'    # 경로에 [lang]이 있으면 대괄호 앞에 \를 붙인다
```

- PR을 올리면 CI(`형식·린트·비밀 키·빌드`)가 `npm test`를 실행한다. 하나라도 실패하면 머지할 수 없다.
- 테스트는 실제 Supabase·Turnstile에 접속하지 않는다. 가짜 응답으로 바꿔 끼워 실행하므로 `.env.local` 없이도 돈다.

## 규칙

- 테스트 파일은 대상 코드 옆에 `이름.test.mjs`로 둔다.
- 테스트 이름은 "무엇이 어떻게 동작한다"는 한국어 문장으로 쓴다. `npm test` 출력에 이 이름이 그대로 나온다.
- ID는 기능 접두어와 번호다. 번호는 다시 쓰지 않고, 테스트를 지우면 그 줄을 지운다.

| 접두어 | 기능               |
| ------ | ------------------ |
| `ADM`  | 관리자 인증        |
| `INQ`  | 문의 저장          |
| `NEWS` | 뉴스룸 공지        |
| `ACM`  | 관리자 콘텐츠 관리 |
