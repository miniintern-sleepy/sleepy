## 관리자 대시보드 (#57, D-47)

- `/admin`은 로그인 전에는 기존 로그인 주소이며 관리자에게는 대시보드다. 로그인 전·권한 없음 화면에는 메뉴를 표시하지 않는다. 별도 레이아웃·noindex·Proxy·페이지/DAL·Action 권한 확인과 RLS를 유지한다.
- 공통 메뉴는 대시보드 / 고객(문의·새 문의 수) / 콘텐츠(FAQ·제품·뉴스룸) / 하단 홈페이지 보기·로그아웃·계정이다. 공유 레이아웃에 두어 탭 전환 시 본문만 로딩한다. 900px 이하는 접힌 메뉴이며 키보드·Escape·포커스 복귀·이동 시 닫기를 제공한다.
- 집계는 새 문의 `status=new`, 발송 실패 `status=new AND reply_status=failed`, FAQ·뉴스 `is_published=true`다. 실패 0건에는 빨간 강조를 하지 않으며 조회 실패는 0건과 구분한다. 새 문의 0건의 요약은 “처리할 새 문의가 없습니다.”다. 집계 하나의 장애는 해당 칸에만 표시한다.
- 처리할 문의는 새 문의만 실패 우선·그 안에서 최신순으로 최대 5건이며 전체 이름·유형·한국 날짜·내용 한 줄을 표시한다. 없으면 “처리할 문의가 없습니다.”를 표시한다. 상세 화면으로 이동해 기존 답변 기능을 쓴다.
- 구매 주소 상태는 F-06과 같은 HTTPS/출시 예정이며 기존 제품 관리로 연결한다. FAQ·기사 추가는 `/admin/faq#faq-form-title`·`/admin/newsroom#news-form-title`로 목록 아래 추가 폼 제목에 바로 연결한다. 비동기 본문 뒤 폼이 나타난 경우에도 해당 제목으로 즉시 이동한다. 수정 폼을 별도 패널로 옮기지 않는다.
- 방문자 통계는 추가하지 않는다(C-05·D-36). 관리자 데이터는 요청 간 캐시하지 않으며 React cache는 렌더 요청 안의 인증/새 문의 집계 중복 제거에만 쓴다.
